
# Aurora Admin Web

## 概述

Aurora Admin Web 用于调用 API，控制所有 plugin 行为。 
其具有登录页面，登录后进入控制台主页面，主页面包含所有 plugin 的控制入口。

**控制台界面设计**：

- 左侧侧边栏一级菜单为所有 plugin，二级菜单为 plugin 具体管理项。
- 顶部栏右侧为用户登录信息
- 其余页面为 plugin 具体控制页面

## Plugin

** API 文档**：`docs/swagger.json`

### dontstarve

**界面设计**：

- 控制台：
  - 启动、停止、重启、更新、安装、卸载按钮
  - 显示服务状态
  - 查看、更新服务设置，如当前启用的存档、token等
  - 额外控制，如查看当前玩家等
  - 查看、更新管理员
- 存档管理：
  - 查看、更新、删除、创建存在
  - 上传、下载存在
- 模组管理：
  - 查看、删除模组

## 开发要求

- 前端代码放在 `aurora-admin-web` 目录
- 前端代码可能过时，API 接口不兼容，需要重新调整
